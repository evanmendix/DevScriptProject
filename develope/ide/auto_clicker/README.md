# 自動圖片識別點擊腳本

這個 Python 腳本可以監控螢幕，當出現指定圖片時自動點擊該位置。

## 功能特色

- 🎯 **智能圖片識別**: 使用 OpenCV 和 PyAutoGUI 進行精準的圖片匹配
- 🖱️ **自動點擊**: 找到目標圖片後自動移動滑鼠並點擊
- ⚙️ **可調整參數**: 支援調整識別信心度、檢查間隔等參數
- 🛡️ **安全機制**: 內建 failsafe 功能，滑鼠移到左上角即可停止
- 📊 **統計資訊**: 顯示點擊次數和運行時間

## 安裝說明

### 1. 安裝 Python 套件

```bash
pip install -r requirements.txt
```

或手動安裝：
```bash
pip install pyautogui Pillow opencv-python
```

### 2. 準備目標圖片

將您想要自動點擊的 UI 元素圖片放入 `target_images/` 目錄中：

- 支援格式：`.png`, `.jpg`, `.jpeg`, `.bmp`, `.gif`
- 建議使用 PNG 格式以保持最佳品質
- 圖片應該只包含要點擊的元素，避免包含太多背景

## 使用方法

### 基本使用

```bash
python auto_click.py
```

### 進階選項

```bash
# 調整識別信心度（預設 0.8）
python auto_click.py --confidence 0.9

# 設定檢查間隔時間（預設 1.0 秒）
python auto_click.py --interval 0.5

# 指定自訂圖片目錄
python auto_click.py --target-dir my_images
```

### 參數說明

| 參數 | 預設值 | 說明 |
|------|--------|------|
| `--target-dir` | `target_images` | 目標圖片目錄路徑 |
| `--confidence` | `0.8` | 圖片識別信心度 (0.0-1.0) |
| `--interval` | `1.0` | 檢查間隔時間（秒） |

## 使用技巧

### 1. 擷取目標圖片

1. 按 `Win + Shift + S` 截取目標 UI 元素
2. 儲存為 PNG 檔案到 `target_images/` 目錄
3. 確保圖片清晰且大小適中（建議 50x50 到 200x200 像素）

### 2. 調整信心度

- **0.7-0.8**: 適合大多數情況，平衡速度和準確性
- **0.8-0.9**: 更精準，但可能較慢
- **0.9-1.0**: 最高準確度，適合固定 UI

### 3. 安全停止

- 按 `Ctrl+C` 停止腳本
- 快速移動滑鼠到螢幕左上角角觸發 failsafe

## 注意事事項

⚠️ **重要提醒**
- 請確保目標圖片版權合法
- 避免用於違反服務條款的行為
- 建議在測試環境中先驗證

🔧 **技術限制**
- 圖片識別可能受解析度影響
- 半透明或動態 UI 可能識別困難
- 需要穩定的螢幕解析度

## 故障排除

### 常見問題

**Q: 找不到圖片？**
A: 嘗試降低信心度到 0.7，或重新截取更清晰的圖片

**Q: 點擊位置不準確？**
A: 確保圖片沒有額外邊距，或調整信心度設定

**Q: 腳本運行很慢？**
A: 增加檢查間隔時間，或減少目標圖片數量
